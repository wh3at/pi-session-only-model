# Session-Only Model Picker 対応表

| 出典 | 目的 | 具体対象 | 役割 | 前後関係 | 初出定義 | 候補語 |
| --- | --- | --- | --- | --- | --- | --- |
| ユーザーの問題提起 | 軽量タスクで高価格モデルを使い続ける無駄を減らす | provider 名とモデル名の全手入力が切り替えを妨げている状況 | 開始条件 | 手入力の負担 → 切り替え回避 → 高価格モデルの継続利用 |  | 手入力負担 |
| スコープ確認 | 通常の Pi と同じ候補から一時モデルを選べるようにする | 現在のセッションで選択対象になっているモデルを検索して一つ選ぶ操作 | 手段 | コマンド実行 → モデル選択 → thinking 選択 | モデル選択とは、現在のセッションで有効な候補から一つを選ぶ操作を指す | モデル選択 |
| スコープ確認 | モデルに合う推論量を毎回意識して選べるようにする | 選択したモデルが対応する thinking level から一つを必ず選ぶ操作 | 手段 | モデル選択 → thinking 選択 → 一括適用 | thinking 選択とは、モデル選択後に対応する thinking level を一つ明示的に選ぶ操作を指す | thinking 選択 |
| キャンセル挙動の確認 | 途中操作で意図しない変更を起こさない | モデルと thinking level の両方が確定した時だけセッション内の状態を変更する処理 | 事象 | 両方を確定 → 一括適用／途中で取消 → 変更なし | 一括適用とは、モデルと thinking level を同じ確定操作の結果として変更することを指す | 一括適用 |
| 既存機能の確認 | 一時変更前の状態へ戻せるようにする | セッション開始時のモデルと thinking level を復元する操作 | 手段 | 一時変更 → reset → 開始時状態 |  | reset |
| 製品境界の確認 | 永続設定を変えず、対話利用だけを改善する | Pi の既定モデル、通常の `/model`、非対話モードを変更対象に含めない境界 | 目的 | セッション内で選択 → セッション終了後は既定設定に従う |  | セッション限定 |

## 実装計画の対象

| 出典 | 目的 | 具体対象 | 役割 | 前後関係 | 初出定義 | 候補語 |
| --- | --- | --- | --- | --- | --- | --- |
| Pi 0.83.0 公開 API | 通常のモデル選択と同じ候補範囲を再利用する | セッションに絞り込みがあればその候補、なければ利用可能なモデル一覧を返す読み取り専用スナップショット | 入力 | コマンド実行 → 候補取得 → モデル選択 | 候補範囲とは、現在の Pi セッションが通常の選択に使うモデル集合を指す | 候補範囲 |
| Pi 公開 TUI API | 全手入力なしで候補を絞り込めるようにする | 検索入力と選択一覧を一つの対話画面として扱うカスタム UI | 手段 | 候補取得 → 検索 → モデル確定 | 検索可能モデル選択とは、provider・ID・表示名で候補を絞り、一つを確定する操作を指す | 検索可能モデル選択 |
| 選択モデルの能力情報 | 選べない推論量を提示しない | 選択したモデルが対応する thinking level の集合 | 制約 | モデル確定 → 対応レベル算出 → thinking 確定 | 対応 thinking level とは、選択モデルに対して Pi が有効と認める推論量を指す | 対応 thinking level |
| 既存 guard | 既定設定とセッション履歴への永続化を抑止する | 両方の選択確定後にだけモデルと thinking level を適用する既存のセッション限定処理 | 境界 | 2段階選択完了 → セッション限定適用 → reset 可能 | 適用境界とは、選択 UI とセッション状態変更を分ける確定点を指す | 適用境界 |
| Pi バージョン境界 | 候補範囲を公開 API だけで正確に取得する | `scopedModels` が ExtensionContext に追加された Pi 0.83.0 | 制約 | 互換性判定 → 対応時だけ拡張を有効化 | 最低対応 Pi とは、この拡張が公開 API だけで契約を満たせる最古の Pi バージョンを指す | 最低対応 Pi |
